# Car Market Analysis

## Project Overview

This project analyzes used-car data from Car Dekho using Python.

The main purpose of this project is to understand used-car prices and find which factors are related to the selling price.

## Problem Statement

Used cars have different prices depending on their age, present price, kilometers driven, fuel type, seller type, transmission, and ownership.

This project uses data analysis and visualization to understand these pricing patterns.

## Dataset

The dataset contains **301 records and 9 columns**.

Main columns:

- Car_Name
- Year
- Selling_Price
- Present_Price
- Kms_Driven
- Fuel_Type
- Seller_Type
- Transmission
- Owner

There were no missing values in the dataset.

Two duplicate records were found and removed.

After cleaning, **299 records** were used for analysis.

## Key Findings

- The dataset contains 299 records after cleaning.
- Petrol is the most common fuel type in the dataset.
- Present Price has the strongest relationship with Selling Price.
- Diesel cars have a higher average selling price than Petrol and CNG in this dataset.
- Automatic cars have a higher average selling price than Manual cars.
- Dealer listings have a higher average selling price than Individual listings.
- Newer cars generally have better selling prices in this sample.

## Important Note

These findings are based only on the given Car Dekho dataset.

They describe patterns in this sample and should not be treated as universal market rules.
